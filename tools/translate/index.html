    How a line works
    One field for each box
    The game shows the line in boxes, one after another. Write each one's words in its own field; the game's codes are kept for you.
    A new line
    A new line in the box. The box shows two lines of about 32 letters; a full-width character counts as two. The game sets a longer one smaller.
    Show the codes
    The line as the pack holds it: {page} starts a new box, {cut} is where the scene does something, and the others, like {F4:01}, are the game's portraits, choices and pauses. You only need this to move one.
    Ctrl + S
    Saves the pack into the game's mods folder. A game that is running shows it within a second or so.
    Ctrl + Enter
    Goes to the next line to translate.
